# Siddhii Janorkar — Web Resume

A clean, professional, ATS-friendly A4 web resume built using **pure HTML5 and CSS3**.

🌐 **Live Demo:** [https://siddhii-janorkar-resume.pages.dev](https://siddhii-janorkar-resume.pages.dev)

---

## 🛠 Tech Stack

- **HTML5** (Semantic structure)
- **CSS3** (Custom styling, A4 print layout, responsive design)
- *No JavaScript, No Frameworks, No Libraries*

---

## 📁 Project Structure

```text
├── index.html       # Resume HTML structure
├── style.css        # Resume styling & print setup
└── assets/
    └── profile.jpg  # Profile photo
```

---

## 🚀 How to Run Locally

Simply double-click `index.html` to open it in any web browser, or run:

```bash
# Using Python
python3 -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.

---

## 🖨️ How to Save as PDF

1. Open `index.html` in your browser.
2. Press **Ctrl + P** (Windows) or **Cmd + P** (Mac).
3. Set **Destination** to `Save as PDF`.
4. Set **Paper Size** to `A4`.
5. Check **Background graphics** under More settings.
6. Click **Save**.
